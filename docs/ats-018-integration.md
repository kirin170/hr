# ATS-018 接入进度

当前面试创建、改期与取消仍使用本地业务记录和 Mock 通知，不会向钉钉创建日程或发送消息。日历客户端包含创建、更新、取消与响应读取方法，但尚未接入持久化同步流程，不应视为已交付。

## 忙闲只读模式

`DINGTALK_CALENDAR_MODE` 默认 `mock`。设为 `live-readonly`，并配置企业应用的 `DINGTALK_CLIENT_ID`、`DINGTALK_CLIENT_SECRET`、`DINGTALK_CORP_ID` 和查询操作者的 `DINGTALK_CALENDAR_OPERATOR_UNION_ID` 后，面试创建和改期会读取所选有效面试官的钉钉忙闲。系统使用已有钉钉 userId 关联和通讯录查询得到 unionId；身份不完整、授权失败、平台返回异常或结果不完整时，页面提示忙闲不可用，仍允许人工排期。

忙闲结果仅用于提示，不自动避让。钉钉忙闲接口未返回可用于排除原面试日程的标识，改期时可能提示原日程自身冲突，需人工判断。该模式只执行读取，不创建或修改钉钉日程，也不发送邀请或通知。
