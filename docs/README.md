## 4. 文档维护约定

1. **接口变更同步**：新增或修改后端 Controller 路由、权限点或标准错误码时，同步更新 [ats-API契约与错误码参考-v1.0.md](ats-API契约与错误码参考-v1.0.md)。
2. **环境变量变更同步**：新增配置项先写入 [backend/.env.example](../backend/.env.example)（禁止填真实密钥），再视需要在运行手册补充说明。
3. **验证报告保留原貌**：`docs/verification/` 下的历史 JSON 报告不可篡改；同一任务补测时追加新版本文件（如 `-v2.json`、`-<topic>-report.json`），并以 `.awr/intake/work-ledger.yaml` 中的 `evidence` 字段标明有效报告。
4. **避免重复粘贴长规则**：新建专题设计文档时，直接引用权威文档章节（如 `PRD §4.2`、`功能需求 §4.12`），不再整段复制业务规则。
